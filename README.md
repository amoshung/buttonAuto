# ⚡ ButtonAuto (Windows 智慧按鈕精靈)

輕量、極速的 Windows 桌面自動按鈕點擊器（Python + Tkinter + OpenCV + `mss` + Win32 原生瞬移點擊）。

## ✨ 功能特色
- **雙螢幕 / 多螢幕全支援**：預設掃描所有螢幕（或自訂多個掃描區域框），發現目標按鈕立即自動點擊。
- **無感瞬移點擊與游標歸位**：命中按鈕時透過 Win32 API 瞬移至按鈕中心完成左鍵點擊，並在約 `18ms` 內將滑鼠游標移回您原本的位置，不打斷手邊操作。
- **Per-Monitor 高 DPI 感知**：支援 Windows 100%、125%、150% 等各種螢幕縮放比例，截圖座標與滑鼠座標 100% 對齊。
- **多掃描區域框 + 滑鼠穿透提示框**：
  - 可在螢幕上連續拉出多個掃描範圍框。
  - 支援在螢幕上顯示**滑鼠可完全穿透 (Click-through)** 的綠色掃描框，標示監控範圍且不影響點擊。
- **多目標按鈕截圖管理**：
  - 內建深色與淺色背景 `Submit` 按鈕模板（`targets/submit_dark.png`、`targets/submit_light.png`）。
  - 支援直接在面板點擊「`＋ 截圖新增目標按鈕 (可多框)`」，一次框選多個新按鈕自動加入比對清單。
- **防誤點自我排除**：自動排除懸浮控制面板視窗本身的座標範圍，絕不會誤點面板上的按鈕縮圖。
- **全域快捷鍵 (`F8`)**：隨時按 `F8` 即可切換啟動 / 停止。

## 🚀 快速開始

1. 直接雙擊執行 **`run.bat`**（首次執行若缺少套件會自動安裝 `opencv-python`、`mss`、`Pillow`、`numpy`）。
2. 或於終端機執行：
   ```bash
   pip install -r requirements.txt
   python main.py
   ```
3. 點擊面板上的 **「▶ 啟動自動掃描 (F8)」** 或按鍵盤 **`F8`** 即可開始自動偵測與點擊。
